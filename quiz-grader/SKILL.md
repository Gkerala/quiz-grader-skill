# 퀴즈 채점

## 순서
1. 채점할 **문제 원문**을 대화에서 찾는다. 원문이 없으면 정답을 지어내지 말고 문제를 달라고 한다.
2. 문항마다 아래 4칸을 한 번에 보여 준다. 내 답은 사용자가 쓴 말을 줄여 인용하고, 고쳐 쓰지 않는다.

   | 문제 | 내 답 | 정답 | 판정 |
   |---|---|---|---|

3. 판정은 세 가지로만 한다.
   - **○** 핵심이 맞다. 표현이 달라도 뜻이 같으면 인정한다.
   - **△** 방향은 맞지만 핵심이 빠졌거나 일부만 맞다. 무엇이 빠졌는지 정답 칸에 짚는다.
   - **✕** 틀렸다. "모름"도 ✕로 센다. 모른다고 적은 건 흠이 아니라 복습 대상이다.
4. 정답 칸은 정답 한 줄과 이유 한 줄로 쓴다. 강의 노트 같은 근거 자료가 대화에 있으면 그 기준으로 하고, 없으면 "일반 지식 기준"이라고 밝힌다.
5. 하위 항목이 있는 문항(ㄱ~ㄹ, O/X 여러 개)은 항목별로 따져서 판정 칸에 "3/4"처럼 적는다.
6. 표 아래에 한 줄 요약을 붙인다. `총 N문제 중 ○ a, △ b, ✕ c`. 영역이 나뉜 퀴즈면 영역별로 한 줄씩 더한다. 같은 주제의 이전 결과가 대화에 있으면 어디가 늘었는지 한 줄로 비교한다.
7. **복습 우선순위**는 △와 ✕만 중요한 순서로 최대 5개 적는다. 항목마다 20~50대가 바로 알아들을 일상 비유 하나와 그 비유의 한계 한 줄을 붙인다. ○인 문항은 다시 가르치지 않는다.
8. 마지막에 다음 행동을 한 줄로 묻는다. (틀린 것만 다시 출제할지, 다음으로 넘어갈지)

## 표 파일로 보기
채팅에서는 긴 표가 줄바꿈되거나 화면을 넘겨서 읽기 어렵다. **문항이 6개를 넘거나 사용자가 표로 보고 싶다고 하면**, 파일을 만들 수 있는 환경에서는 HTML 파일 하나로 저장하고 경로를 알려 준다. 서버는 필요 없고 파일을 열기만 하면 된다. 채팅에는 한 줄 요약과 복습 우선순위만 남기고 표를 또 쓰지 않는다.

**HTML을 직접 쓰지 말고, 이 스킬 폴더의 `render.py`에 JSON만 넘긴다.** CSS와 태그는 스크립트가 만든다. 그래야 쓰는 양이 줄어 빠르다.

```bash
python <이 스킬 폴더>/render.py "<훈련과정 폴더>/quiz-result-날짜-주제.html" <<'JSON'
{"title":"...","subtitle":"...",
 "sections":[{"name":"A. 영역 이름","rows":[
   {"n":1,"q":"문제","a":"내 답","c":"정답과 이유 한 줄","v":"△","note":"빠진 것"}]}],
 "review":["복습 항목 + 일상 비유 + 한계"]}
JSON
```
- `v`는 ○ △ ✕ 중 하나다. 점수 요약은 `v`를 세어 스크립트가 만든다. `note`는 선택이다.
- 글 안의 `**굵게**`만 서식으로 바뀌고, 나머지 `<` `>`는 글자로 보인다.
- **저장 위치는 해당 장의 `훈련과정/` 폴더**다. 경로는 `모듈/<N_모듈이름>/<N장_강의이름>/훈련과정/`이다. 어느 장인지는 퀴즈의 주제로 정하고, 애매하면 `아이펠/일차별/현황.md`에서 가장 최근에 모듈/장이 적힌 행을 따른다. 그래도 정할 수 없으면 사용자에게 묻는다. 새 장 폴더를 만들지 않는다.
- 파일 이름은 `quiz-result-날짜-주제.html`이다. 같은 이름이 이미 있으면 스크립트가 `-2`, `-3`을 붙여 **덮어쓰지 않는다.** 저장한 전체 경로를 사용자에게 알려 준다.
- 이 파일들은 `.gitignore`로 GitHub에 올리지 않는다.
- (이 저장소 밖에서 쓰는 경우) 해당 장 폴더가 없으면 현재 작업 폴더에 저장한다.
- Python이 없거나 스크립트가 실행되지 않으면, 같은 구성(점수 요약, 구역별 표, 복습 우선순위)의 HTML을 직접 써서 저장한다. 파일을 아예 만들 수 없는 환경이면 채팅 표로 답한다.

## 규칙
- 사용자가 채점에 이의를 달면 문제 원문을 다시 읽고, 문제가 모호했다면 정직하게 재채점한다.
- 길게 가르치지 않는다. 재설명은 △와 ✕에만, 항목당 몇 줄로 한다.
- 개인 정보(실명, 학교, 생년월일)는 결과에 적지 않는다.
